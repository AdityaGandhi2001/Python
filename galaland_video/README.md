# Galaland – Happy Diwali (festive)

`Galaland_Happy_Diwali_Festive.mp4` is rendered by `festive.py` (run `python3 festive.py` in this folder).

## Use your own photos
Replace the files in `photos/` with your own, keeping the same file names:
- `car00.jpg` … `car17.jpg`: the eight car shots, in the order they appear in `CARS` in `festive.py`
- `d*.jpg`: the Diwali background shots

Then run the script again. If all the photos are your own, you can also remove the credits screen.
